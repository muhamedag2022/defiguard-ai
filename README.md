# DeFi Guard AI

🛡️ **AI-Powered Smart Contract Security Shield** for HashKey Chain  
Horizon Hackathon 2026 – Mohammed Agouram (@muhamedag2022)

## Overview
DeFi Guard AI is an instant AI-powered security platform that analyzes smart contracts for vulnerabilities **in under 60 seconds**.  
It protects developers (pre-deployment) and users (pre-transaction) from exploits like reentrancy attacks, access control flaws, and more.  

Built conceptually for **Horizon Hackathon** on **HashKey Chain** – focusing on regulated DeFi, RWA tokenization, and institutional-grade security.

### The Problem
- Over **$3B** lost to DeFi hacks in recent years  
- **90%** of exploits are preventable with proper checks  
- Traditional audits cost **$50K–$200K** and take weeks  
- Small projects & individual users have no affordable real-time protection

### Our Solution (MVP Demo)
- **Instant mock analysis** simulation  
- Security score (e.g., 72/100) with severity levels (Critical/Medium/Low)  
- Detailed vulnerability reports + **auto-suggested fixes** in Solidity  
- Future: Full AI engine (GPT-4 + static tools like Slither), browser extension for real-time warnings
